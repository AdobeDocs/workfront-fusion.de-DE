# Dateien aus dem Speicher herunterladen

Mit dem Fusion-Speicherbereich können Sie Dateien aus Ihrem Adobe-Speicher herunterladen.

Einen Überblick über Speicher finden Sie unter [Speicherübersicht](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

## Datei herunterladen

1. Klicken Sie in Workfront Fusion **linken** auf „Speicher“.
1. Navigieren Sie zum Repository und Ordner, der die Datei enthält, die Sie herunterladen möchten.
1. Wählen Sie eine Datei aus, indem Sie in der Tabelle darauf klicken.
1. Klicken Sie in der angezeigten Aktionsleiste auf **Herunterladen**.

Ein **Fortschrittsbanner** wird oben rechts angezeigt und zeigt:

* Dateiname
* Download-Fortschrittsprozentsatz
* Übertragene Bytes
* Eine Schaltfläche **Abbrechen** zum Abbrechen des Downloads

Die Datei wird am standardmäßigen Download-Speicherort des Browsers gespeichert.

## Herunterladen einer bestimmten Version einer Datei

1. Klicken Sie in Workfront Fusion **linken** auf „Speicher“.
1. Navigieren Sie zum Repository und Ordner, der die Datei enthält, die Sie herunterladen möchten.
1. Wählen Sie eine Datei aus und klicken Sie in der Aktionsleiste auf **Versionen**.
1. Klicken Sie im Bedienfeld **Versionsverlauf** neben der Version **die Sie herunterladen möchten, auf Herunterladen**.

Wenn ein Download fehlschlägt, wird eine Popup-Benachrichtigung angezeigt: *Download fehlgeschlagen - Die Datei konnte nicht heruntergeladen werden. Bitte erneut versuchen.“*

Weitere Informationen zu Dateiversionen finden Sie unter [Dateiversionsverlauf im Speicher anzeigen](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/view-storage-file-version-history.md).
