# Dateien in Speicher hochladen

Sie können mithilfe des Speicherbereichs eine Datei aus Workfront Fusion in den Adobe-Cloud-Speicher hochladen.

Der Upload ist beim Durchsuchen eines Ordners verfügbar (nicht in der Ordnerliste der obersten Ebene).

* Einen Überblick über Speicher finden Sie unter [Speicherübersicht](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).
* Anweisungen zum Erstellen eines Upload-Szenarios finden Sie unter [Erstellen von Szenarien aus dem Speicher](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/create-scenarios-from-storage.md).


## Datei hochladen

1. Klicken Sie in Workfront Fusion **linken** auf „Speicher“.
1. Navigieren Sie zum Repository und Ordner, in den Sie eine Datei hochladen möchten.
1. Klicken Sie auf die Dropdown **Schaltfläche „Datei hochladen**.
1. Wählen Sie **„Datei hochladen“**, um sie direkt hochzuladen.

   Eine Dateiauswahl wird geöffnet.
1. Datei zum Hochladen auswählen.

   Ein **Fortschrittsbanner** wird oben rechts angezeigt und zeigt:

   * Dateiname
   * Upload-Fortschrittsprozentsatz
   * Übertragene Bytes
   * Eine Schaltfläche **Abbrechen** zum Stoppen des Uploads

Nach dem Hochladen wird die Datei in der Ordnerliste angezeigt. Die Spalte **Size** kann vorübergehend den *„Processing…“* anzeigen, während der Adobe-Speicher die Datei im Backend verarbeitet. Die tatsächliche Dateigröße wird nach Abschluss des Vorgangs angezeigt. Dies kann durch Aktualisieren der Seite überprüft werden.

## Upload-Beschränkungen

* Maximale Dateigröße: **GB**.
