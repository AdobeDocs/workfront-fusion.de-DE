# Löschen von Dateien aus dem Speicher

Einen Überblick über Speicher finden Sie unter [Speicherübersicht](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

1. Klicken Sie in Workfront Fusion **linken** auf „Speicher“.
1. Navigieren Sie zum Repository und Ordner, der die Datei enthält, die Sie löschen möchten.
1. Wählen Sie eine Datei aus, indem Sie in der Tabelle darauf klicken.
1. Klicken Sie in **Aktionsleiste auf** Löschen“.
1. Bestätigen Sie, dass Sie die Datei löschen möchten.


Die Datei wird aus dem Speicherbereich entfernt.

>[!NOTE]
>
>Nur Dateien können gelöscht werden. Das Löschen von Ordnern wird in dieser Version nicht unterstützt.
