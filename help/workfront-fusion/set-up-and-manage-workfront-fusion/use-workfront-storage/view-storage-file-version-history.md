# Anzeigen des Dateiversionsverlaufs im Speicher

Einen Überblick über Speicher finden Sie unter [Speicherübersicht](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

Dateien im Adobe-Speicher können mehrere Versionen haben.

## Anzeigen des Versionsverlaufs

1. Klicken Sie in Workfront Fusion **linken** auf „Speicher“.
1. Navigieren Sie zum Repository und Ordner, der die Datei enthält, für die Sie Versionen anzeigen möchten.
1. Wählen Sie eine Datei aus und klicken Sie in der Aktionsleiste auf **Versionen**.
Ein Bedienfeld **Versionsverlauf** wird geöffnet.
Die Versionen werden als „Newest-First“ aufgelistet und zeigen jeweils Folgendes an:
   * Versionsnummer
   * Datum
   * Eine **Download**-Schaltfläche

   Die aktuelle (neueste) Version ist mit einem **„current“** Badge gekennzeichnet

Informationen zum Herunterladen einer bestimmten Version finden Sie unter [Herunterladen einer bestimmten Version](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/download-files-from-storage.md#download-a-specific-version) im Artikel Herunterladen von Dateien aus dem Speicher.
