# Workfront Fusion-Veröffentlichungsaktivität: Woche vom 10. August 2026

Auf dieser Seite werden alle Verbesserungen beschrieben, die in Adobe Workfront Fusion in der Woche vom 10. August 2026 vorgenommen wurden.

Eine Liste aller aktuellen Änderungen finden Sie unter [Adobe Workfront Fusion-Veröffentlichungen](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Eine Liste der letzten Fehlerbehebungen in Workfront Fusion finden Sie auf der Seite [Wartungs-Updates für Workfront](https://experienceleague.adobe.com/de/docs/workfront-known-issues/releases/current-updates). Suchen Sie nach Updates mit der Bezeichnung „Workfront Fusion-Wartungs-Update“.

## Festlegen von Team- oder Szenario-Benachrichtigungsoptionen für IMS-Organisationen.

Um Teams eine feinere Kontrolle über die Benachrichtigungen zu geben, die sie erhalten, können IMS-Organisationen jetzt jeden Benachrichtigungstyp unabhängig voneinander aktivieren oder deaktivieren, anstatt alle Benachrichtigungen zusammen zu aktivieren oder zu deaktivieren.

Sie können steuern, für welche Situationen Benachrichtigungen gesendet werden:

* **Bei Warnung benachrichtigen**: Fusion sendet eine Benachrichtigung, wenn eine Szenarioausführung eine Warnung protokolliert.
* **Bei Fehler benachrichtigen**: Fusion sendet eine Benachrichtigung, wenn die Ausführung eines Szenarios fehlschlägt.
* **Bei deaktiviertem Szenario benachrichtigen**: Fusion sendet eine Benachrichtigung, wenn ein Szenario automatisch deaktiviert wird, z. B. nach zu vielen aufeinander folgenden Fehlern.

Benachrichtigungen können auch auf Szenario-Ebene festgelegt werden, wodurch die Einstellung auf Team-Ebene außer Kraft gesetzt wird.

Diese Funktion war zuvor auf Nicht-IMS-Organisationen beschränkt.

Weitere Informationen finden Sie unter [Benachrichtigungsoptionen festlegen](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/set-up-orgs-teams-and-users/set-team-notification-options.md).

## MCP Agent Connector und Modul jetzt verfügbar

Sie können jetzt Workfront Fusion verwenden, um KI-Sprachmodelle mithilfe des Model Context Protocol (MCP) mit Ihren Anwendungen zu verbinden. Sie konfigurieren MCP-Server, die dem KI-Modell Zugriff auf die Anwendung gewähren, und senden ihm dann eine Eingabeaufforderung, um Informationen von dieser Anwendung abzurufen oder darauf zu reagieren.

Mit dem MCP Agent-Modul können Sie:

* Verarbeiten Sie eine Eingabeaufforderung mit einem Sprachmodell und den von Ihnen angegebenen MCP-Servern

Weitere Informationen finden Sie unter [MCP Agent (Model Context Protocol)-Modul](/help/workfront-fusion/references/apps-and-modules/tools-and-transformers/model-context-protocol-mcp-connector.md).
