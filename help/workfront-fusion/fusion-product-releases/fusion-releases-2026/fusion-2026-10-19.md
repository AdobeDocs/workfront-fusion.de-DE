# Workfront Fusion-Veröffentlichungsaktivität: Woche vom 19. Oktober 2026

Auf dieser Seite werden alle Verbesserungen beschrieben, die in Adobe Workfront Fusion in der Woche vom 19. Oktober 2026 vorgenommen wurden.

Eine Liste aller aktuellen Änderungen finden Sie unter [Adobe Workfront Fusion-Veröffentlichungen](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Eine Liste der letzten Fehlerbehebungen in Workfront Fusion finden Sie auf der Seite [Wartungs-Updates für Workfront](https://experienceleague.adobe.com/de/docs/workfront-known-issues/releases/current-updates). Suchen Sie nach Updates mit der Bezeichnung „Workfront Fusion-Wartungs-Update“.

## Neue Zuordnungsvariablen

Im Zuordnungsbereich sind jetzt sechs neue allgemeine Variablen verfügbar. Sie bieten einsatzbereite Szenario- und Ausführungslinks, API-URLs und Eigentümerkennungen, damit Sie diese Werte in zugeordnete Felder aufnehmen können, ohne URLs oder hartcodierte Team- und Organisations-IDs zu erstellen.

* `scenarioUrl`: Ein Link zum aktuellen Szenario in der Benutzeroberfläche von Fusion.
* `executionUrl`: Ein Link zur aktuellen Szenarioausführung in der Fusion-Benutzeroberfläche.
* `scenarioApiUrl`: Die Fusion-API-URL für das aktuelle Szenario.
* `executionApiUrl`: Die Fusion-API-URL für die Details der aktuellen Ausführung.
* `teamId`: Die ID des Fusion-Teams, dem das aktuelle Szenario gehört.
* `organizationId`: Die ID der Fusion-Organisation, die mit der aktuellen Ausführung verknüpft ist.

Diese Variablen erweitern die vorhandenen Variablen `executionID`, `scenarioID`, `scenarioName`, `triggerTimestamp` und `operationsConsumed`.

Weitere Informationen finden Sie unter [Allgemeine Funktionen](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md).

## Änderungen am Fusion-Connector

Der Workfront Fusion-Connector unterstützt jetzt mehr Aktionen zur Verwaltung Ihrer Fusion-Organisation innerhalb eines Szenarios.

**Neue Module und Aktionen**

* **Klonen eines Datensatzes** Sie können jetzt einen Hook klonen. Verwenden Sie Abhängigkeiten, um die Abhängigkeiten des Quell-Hooks dem Ziel zuzuordnen, wie Sie es beim Klonen eines Szenarios tun.
* **Datensatz löschen:** Sie können jetzt eine Verbindung, einen Datenspeicher, einen Datenspeicherdatensatz, Datenspeicherdatensätze (Bulk), eine Datenstruktur, einen Hook, einen Schlüssel, ein Szenario oder ein Team löschen.
* **Einträge auflisten:** Sie können jetzt DLQs, Organisationen, Teams und Benutzer auflisten.
* **Datensatz lesen:** Sie können jetzt ein DLQ, die aktuelle Organisation, ein Team, einen Benutzer oder den autorisierten Benutzer lesen.
* **Datensatzabhängigkeiten abrufen:** Sie können jetzt die Abhängigkeiten eines Hooks abrufen.
* **Datensatzabhängige Elemente abrufen** Dieses neue Modul gibt die abhängigen Elemente von Datenspeichern, Erweiterungspunkten und Szenarien zurück. Führen Sie sie aus, bevor Sie eine Ressource löschen, um zu überprüfen, ob etwas davon abhängt.

**Weitere Updates**

* Eigenschaftsfilter, die als mehrwertig markiert sind, akzeptieren jetzt durch Kommas getrennte Werte mit den Operatoren `==` und `!=`. Derzeit wird dies nur von der `id` Eigenschaft für Benutzer unterstützt (z. B. `id==123,456`).
* Beim Löschen der Warteschlange eines Hooks ersetzt der `except` den `excludeId` und kann nur verwendet werden, wenn alle Elemente gelöscht werden. Der `id` akzeptiert jetzt eine kommagetrennte Liste. Eine neue 423-Antwort wird zurückgegeben, wenn bereits ein Löschvorgang ausgeführt wird.
* Beim Abrufen von Szenarien oder eines einzelnen Szenarios können Sie jetzt den `fields`-Parameter verwenden, um auszuwählen, welche Felder zurückgegeben werden.

Weitere Informationen finden Sie unter [Workfront Fusion-](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).
