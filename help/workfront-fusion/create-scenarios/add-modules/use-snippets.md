# Speichern und Wiederverwenden von Szenarioabschnitten mit Snippets

>[!NOTE]
>
>Diese Funktion ist nur in der neuen Version des Szenario-Editors verfügbar. Weitere Informationen finden Sie unter [Neue und klassische Erlebnisse](/help/workfront-fusion/get-started-with-fusion/navigate-fusion/scenario-editor.md#new-and-classic-experiences) im Artikel Szenario-Editor.

Ein Snippet ist eine Gruppe von Modulen, die Sie als Einheit speichern. Sie können anderen Szenarien einen Ausschnitt hinzufügen, sodass Sie denselben Abschnitt eines Szenarios nicht mehrmals erstellen müssen.

Mit dem Snippets-Bedienfeld können Sie Snippets suchen, taggen, in der Vorschau anzeigen, anheften und sortieren, in ein Szenario ziehen und dort ablegen, importieren und exportieren und für Teams oder Organisationen freigeben oder eine Kopie an einen anderen Benutzer senden.

## Erstellen eines Snippets

1. Klicken Sie auf **[!UICONTROL Registerkarte]** Szenarien“ im linken Bedienfeld.
1. Wählen Sie das Szenario aus, das die Module enthält, die Sie speichern möchten.
1. Klicken Sie auf eine beliebige Stelle im Szenario, um den Szenario-Editor aufzurufen.
1. Umschalt + Klicken Sie auf alle Module, die Sie in den Ausschnitt aufnehmen möchten.
1. Klicken Sie mit der rechten Maustaste auf eines der ausgewählten Module und wählen Sie Ausschnitt erstellen aus.
1. Geben Sie einen Namen für den Ausschnitt ein.
1. Klicken Sie auf **Speichern**.

## Hinzufügen eines Ausschnitts zu einem Szenario

1. Klicken Sie auf **[!UICONTROL Registerkarte]** Szenarien“ im linken Bedienfeld.
1. Wählen Sie das Szenario aus, in dem Sie einen Ausschnitt hinzufügen möchten.
1. Klicken Sie auf eine beliebige Stelle im Szenario, um den Szenario-Editor aufzurufen.
1. Klicken Sie auf das **Snippets**-Symbol ![Snippets](assets/snippets-icon.png) im Bereich Steuerelemente.

   Möglicherweise müssen Sie auf das Dreipunkt-Symbol im Bereich Steuerelemente klicken, um das Snippets-Symbol anzuzeigen.

1. (Optional) Wählen Sie einen Ausschnitt aus, um ihn in der Vorschau anzuzeigen.
1. Klicken Sie auf den Ausschnitt, um ihn dem Editor hinzuzufügen.
1. Verbinden Sie das Snippet mit Ihrem Szenario.
1. Aktualisieren Sie alle Felder im Snippet, um mit dem Szenario zu arbeiten, dem es hinzugefügt wurde.

## Organisieren von Snippets

Im Bedienfeld Snippets haben Sie folgende Möglichkeiten:

* Suchen Sie nach einem Snippet.
* Pin-Snippets, die Sie häufig verwenden.
* Exportieren Sie einen Ausschnitt als JSON-Datei.
* Geben Sie Snippets für andere Organisationen, Teams oder Benutzer frei.
* Vorschau eines Ausschnitts vor dem Hinzufügen zu einem Szenario.
* Sortiert die Liste der Snippets.

## Freigeben von Snippets

Sie können ein Snippet für ein Team oder eine Organisation freigeben oder eine Kopie direkt an einen anderen Benutzer senden.

Sie haben folgende Möglichkeiten:

* **Für ein Team oder eine Organisation freigeben**: Geben Sie das Snippet frei, damit andere Mitglieder es verwenden können.
* **Kopie an einen Benutzer senden**: Senden einer Kopie an einen Benutzer. Der/die Benutzende erhält eine eigene Kopie.


1. Klicken Sie auf das **Snippets**-Symbol ![Snippets](assets/snippets-icon.png) im Bereich Steuerelemente.
1. Bewegen Sie den Mauszeiger über das Snippet, das Sie freigeben möchten, und klicken Sie dann auf das Freigabesymbol, wenn es angezeigt wird.
1. Wählen Sie aus, ob Sie den Ausschnitt für andere Organisationen, Teams oder Benutzende freigeben möchten.
1. Klicken Sie auf **Weiter**.
1. Wählen Sie die Organisation oder das Team aus, für die bzw. das Sie das Snippet freigeben möchten, oder geben Sie die Benutzer-ID des Benutzers ein, für den Sie das Snippet freigeben möchten.
1. Klicken Sie auf **Freigabe**.

Snippets, die für Sie freigegeben sind, werden auf der Registerkarte **Für mich freigegeben** im Bedienfeld Snippets angezeigt.

## Importieren und Exportieren von Snippets

Sie können einen Ausschnitt in eine JSON-Datei exportieren und in ein anderes Szenario oder eine andere Umgebung importieren.

1. Klicken Sie auf das **Snippets**-Symbol ![Snippets](assets/snippets-icon.png) im Bereich Steuerelemente.
1. Bewegen Sie den Mauszeiger über das Snippet, das Sie freigeben möchten, und klicken Sie dann auf das Exportsymbol, wenn es angezeigt wird.
